# Triage Labels

Five canonical triage states. The `triage` skill moves issues through these.

| Label              | Meaning                                                      |
|--------------------|--------------------------------------------------------------|
| `needs-triage`     | New issue, not yet reviewed by a human or agent              |
| `needs-info`       | Blocked — waiting on information from the reporter or owner  |
| `ready-for-agent`  | Spec is clear, agent can pick this up autonomously           |
| `ready-for-human`  | Needs a human decision before work can continue              |
| `wontfix`          | Accepted as known; will not be addressed                     |

These are recorded in the issue file's `labels:` array, e.g.:

```yaml
labels: [ready-for-agent]
```
