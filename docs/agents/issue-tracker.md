# Issue Tracker — GitHub Issues

This repo uses **GitHub Issues** on `MirouBagui/portfolio` as its issue tracker. Drive it with `gh`.

> The repo is **public**. Never put confidential material in an issue: no NDA-covered figures, client names beyond what the live site already shows, credentials, or internal URLs.

> On this machine `gh` runs through a mise shim that prints `mise ⇢ …` lines on stdout. Pipe through `2>/dev/null | grep -v '^mise'` before parsing any output.

## Basics

```bash
gh issue list --state open
gh issue list --label <label>
gh issue view <n> --comments
gh issue create --title "<title>" --body-file <file> --label <label>
gh issue comment <n> --body-file <file>
gh issue close <n>
```

Triage labels are listed in [triage-labels.md](./triage-labels.md).

## Wayfinding operations

Used by `/wayfinder`.

| Concept | How it is expressed here |
|---|---|
| **Map** | One issue labelled `wayfinder:map` |
| **Ticket** | Issue labelled `wayfinder:<research\|prototype\|grilling\|task>`, attached to the map as a native **sub-issue** |
| **Claim** | Assign the ticket: `gh issue edit <n> --add-assignee @me` (unassigned + open = unclaimed) |
| **Blocking** | Native issue dependencies ("blocked by") |
| **Resolution** | Resolution comment on the ticket, close it, then add a line to the map's *Decisions so far* |
| **Assets** | Linked from the issue (branch, file path, PR), never pasted in. Research findings live on a `research/<name>` branch |

REST calls — sub-issue and dependency endpoints take the issue's numeric **`id`**, not its `number`:

```bash
id() { gh api repos/MirouBagui/portfolio/issues/$1 --jq .id 2>/dev/null | grep -v '^mise'; }

# attach ticket <t> to map <m>
gh api -X POST repos/MirouBagui/portfolio/issues/<m>/sub_issues -F sub_issue_id=$(id <t>)

# ticket <t> is blocked by <b>
gh api -X POST repos/MirouBagui/portfolio/issues/<t>/dependencies/blocked_by -F issue_id=$(id <b>)

# children of a map / blockers of a ticket
gh api repos/MirouBagui/portfolio/issues/<m>/sub_issues --jq '.[] | "\(.number) \(.state) \(.title)"'
gh api repos/MirouBagui/portfolio/issues/<t>/dependencies/blocked_by --jq '.[] | "\(.number) \(.state)"'
```

**Frontier** = the map's sub-issues that are open, unassigned, and whose every `blocked_by` issue is closed.
